# Прости…

Персональная страница с фотографиями и музыкальным плеером.

## Публикация на GitHub Pages

В репозитории открой **Settings → Pages**, выбери источник **GitHub Actions**. Workflow из `.github/workflows/pages.yml` опубликует сайт при отправке изменений в ветку `main`.

Сайт использует файлы из `assets/photos` и `assets/music`.
